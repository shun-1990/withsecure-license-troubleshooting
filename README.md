# WithSecureセットアップ・ライセンス未承認の切り分けと再実行

## どんな状態か

アプリは入っているのに、ライセンスキー（合言葉のようなもの）が通っていない状態です。
画面にこう出ます。

- `Your subscription is not activated. Please enter a valid subscription key to start using the product`

## 今回の実際の原因（確定）

**指定コマンドを複数行のままPowerShellに貼ったことです。**

PowerShellでは、1行目だけが `msiexec` として実行され、2行目・3行目は別のコマンドとして扱われてエラーになります（`CommandNotFoundException`）。

- 渡ったもの：1行目だけ（インストーラーとキー）
- **渡らなかったもの：`PROFILE_ID` と `PROXY_SERVER`（プロキシ指定）**
- プロキシが渡らないと管理側へ接続できないので、アプリだけ入ってライセンスが承認されません

見分け方：貼り付けたあとに `>>` が出て、`PROFILE_ID=...` や `LANGUAGE=...` が赤いエラーになったら、このパターンで確定です。

## 結論：やること

**間違った条件で入っているアプリを一度アンインストールして、指定コマンドを「1行」で入れ直します。**
本番環境では、指定されたコマンド以外のツールは使いません。

> ライセンスキーの実物は、このページやチャットに書かないでください。下では `<キー>` と書きます。`PROFILE_ID` と `PROXY_SERVER` の値は、手順書に書かれた値をそのまま使います。

## 手順（上から順にやるだけ）

### 1. 今入っているアプリをアンインストールする

Windowsの通常の方法（設定 > アプリ、またはコントロールパネル）でWithSecureを削除します。終わったら再起動します。

### 2. 貼り付けるスクリプトを用意する（コピペ用・1行）

メモ帳に下の1行をコピーし、`<キー>` の部分だけ提供されたライセンスキーに書き換えます。`PROFILE_ID` と `PROXY_SERVER` は手順書の値をそのまま入れます。**途中で改行を入れないこと。**

```powershell
msiexec /i ElementsAgentOfflineInstaller.msi /qn VOUCHER=<キー> PROFILE_ID=<手順書の値> PROXY_SERVER=<手順書の値> DISABLE_DEFENDER=1 LANGUAGE=ja
```

### 3. 実行する

1. PowerShellを **管理者** で開く
2. MSIファイルのあるフォルダへ移動する（手順書の `cd` コマンド）
3. 手順2の1行をすべて選択してコピーし、ターミナルに貼り付けて Enter

成功のサイン：

- [ ] `>>` が出ない
- [ ] `PROFILE_ID=...` や `LANGUAGE=...` の赤いエラーが出ない
- [ ] 画面は変わらなくてOK（裏側でインストールが進みます）

### 4. 待ってから確認する（ここまで見て完了）

実行後は何もせず **2〜3分** 待ちます。そのあと、手順書の「インストール完了の確認」と同じ方法で見ます。

- [ ] 画面右下のタスクトレイ（「^」マークの中）に、WithSecureのアイコンが表示されている
- [ ] アイコンをクリックしてメイン画面を開き、緑色の盾マークと **「コンピュータは保護されています」** と表示されている
- [ ] 製品名が **WithSecure Elements EPP for Servers** になっている

この状態がゴールです。逆に、開いて「セットアップ（ライセンスキーコード入力）」画面になったら、まだ未登録なので完了ではありません。

## ダメだったとき

| 症状 | やること |
|---|---|
| `>>` が出た／`PROFILE_ID` などが赤エラー | また改行が入っています。手順2からやり直し（必ず1行） |
| 1行で入れたのに未承認のまま | 値が手順書どおりか確認する（キー、PROFILE_ID、プロキシの3つ）。特にキーの打ち間違いと前後の空白 |
| 上の2つでも直らない | 指定外のツールは試さず、エラーの画面を撮って担当へエスカレーションする。そのときキー実物は画面に入れない |

## やってはいけないこと

- **コマンドを複数行のまま貼らない** ― 今回の原因そのものです
- **インストーラーのファイル名を変えない**
- **エラーが出たのに「完了」にしない** ― 手順4の確認2つがそろうまで完了にしません

## 助けを求めるときに渡すもの

1. エラーの文面・画面（キーの部分は伏せる）
2. 手順3で `>>` や赤エラーが出たかどうか

## 改善案：コードの何が悪いか（手順書側への提案用）

悪いのはコマンドの中身（パラメータ）ではなく、**渡し方**です。

- 複数行に分かれたコマンドをそのまま貼ると、PowerShellでは1行目しか実行されない作りになっている
- 実行結果（終了コード）を確認する仕組みがなく、失敗しても「完了」と誤認しやすい
- 「2〜3分待つ」とあるだけで、成功したかどうかをその場で判定できない

複数行でも壊れない形にするなら、パラメータを配列にまとめる書き方が安全です（括弧が閉じるまでPowerShellが続きとして扱うため、途中で実行されません）。あわせて、終わるまで待ち、失敗したら止まる形にします。

```powershell
$installArgs = @(
  '/i', 'ElementsAgentOfflineInstaller.msi',
  '/qn',
  'VOUCHER=<キー>',
  'PROFILE_ID=<手順書の値>',
  'PROXY_SERVER=<手順書の値>',
  'DISABLE_DEFENDER=1',
  'LANGUAGE=ja'
)
$p = Start-Process msiexec.exe -ArgumentList $installArgs -Wait -PassThru -NoNewWindow
if ($p.ExitCode -ne 0) { throw "インストールに失敗しました。ExitCode=$($p.ExitCode)" }
Write-Host 'インストール完了。2〜3分待ってから確認手順へ。'
```

※これは手順書側への改善提案用です。本番作業では、承認されるまでは指定されたコマンドを1行にして使います。
