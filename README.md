# WithSecureセットアップ・ライセンス未承認の切り分けと再実行

## どんな状態か

アプリは入っているのに、ライセンスキー（合言葉のようなもの）が通っていない状態です。
画面にこう出ます。

- `Your subscription is not activated. Please enter a valid subscription key to start using the product`

## 結論：やることは1つだけ

**アプリは消さないでください。キーを入れ直すだけです。**

消して入れ直すと、管理画面に同じサーバーが2つ出てしまいます。
アンインストールは、最後の手段です（下の「どうしても直らないとき」だけ）。

> ライセンスキーの実物は、このページやチャットに書かないでください。下では `<キー>` と書きます。

## 今回の実際の原因（確定）

**コマンドを複数行のまま貼ったことです。**

PowerShellでは、1行目だけが `msiexec` として実行され、2行目・3行目は別のコマンドとして扱われてエラーになります（`CommandNotFoundException`）。

- 渡ったもの：1行目だけ（インストーラーとキーの一部）
- **渡らなかったもの：`PROFILE_ID` と `PROXY_SERVER`（プロキシ指定）**
- プロキシが渡らないと管理側へ接続できないので、アプリだけ入ってライセンスが承認されません

見分け方：貼り付けたあとに `>>` が出て、`PROFILE_ID=...` や `LANGUAGE=...` が赤いエラーになったら、このパターンで確定です。

直し方：指定されたコマンド以外は使わず、**メモ帳で必ず1行につなげてから**貼り直します。すでに間違った条件で入っている分は、アンインストールしてから正しい1行で入れ直すのが確実です。

## 手順（上から順にやるだけ）

### 1. 管理画面でキーを確認する

WithSecureの管理画面（Elements Security Center）を開き、**Management > Subscriptions** を見ます。

- [ ] キーの期限が切れていない
- [ ] サーバー用のキーである（PC用のキーでは通りません）
- [ ] 使える台数が上限に達していない

1つでもダメなら、端末を触っても直りません。先にキーを直してください。

### 2. サーバーを再起動する

1回だけ再起動して、アプリの表示が変わらないか見ます。変わらなければ次へ。

### 3. コマンドを1つ実行する

PowerShellを **管理者** で開いて、これをコピペします。`<キー>` の部分だけ自分のキーに変えます。

```powershell
cd "C:\Program Files (x86)\F-Secure\PSB\"
.\ws_oneclient_logout.exe --keycode <キー>
$LASTEXITCODE
```

- 最後に **0** と出れば成功です
- 0以外が出たら、その数字をメモして、下の「ダメだったとき」へ
- フォルダがないと言われたら、`C:\Program Files (x86)\F-Secure\` の中も探してください

### 4. 確認する（ここまで見て完了）

- [ ] アプリを開いて、状態がすべて緑になっている
- [ ] 管理画面の **Environment > Devices** に、このサーバーが出ている

「アプリが入った」だけでは完了ではありません。この2つがそろって完了です。

## ダメだったとき（症状別に1つだけやる）

| 症状 | やること |
|---|---|
| 0以外の数字が出た／ずっと未承認のまま | 通信チェックを実行する：`C:\Program Files (x86)\F-Secure\PSB\ui\wsconnectionchecker.exe`。失敗した項目（ネット接続やプロキシ）を直してから、手順3をもう1回 |
| `You cannot use the subscription key...` と出る | そのサーバーが管理画面で一度削除され、ブロックされています。管理画面の **Subscriptions** で対象キーの「…」→ **Restore devices from blocklist** を押してから、手順3をもう1回 |
| 上の2つでも直らない | ここだけアンインストールOK。下の「どうしても直らないとき」へ |

## どうしても直らないとき（最終手段）

1. アプリをアンインストールして、再起動する
2. 管理画面の Devices から、古いサーバーが消えたか確認する
3. 入れ直す。ファイル名は変えないこと（下の注意参照）。EXEで入れる場合は最後に `--use_smbios_guid` を付けると、同じサーバーが2つになりません

## やってはいけないこと

- **インストーラーのファイル名を変えない** ― EXEのファイル名にはキーが含まれています。変えるとキーが渡らず、今回のように「アプリだけ入ってキー未承認」になります
- **同じPowerShellを何度も流し直さない** ― 入っている状態でインストーラーを流しても、キー登録は素通りすることがあります。直すときは手順3のコマンドです
- **エラーが出たのに「完了」にしない** ― コマンドの最後の数字が 0 かどうかを必ず見てください

## 助けを求めるときに渡すもの

この3つがあれば、原因をすぐ絞れます。

1. エラーの文面（キーの部分は伏せる）
2. 手順3で出た数字（0以外の数字）
3. 診断ファイル ― WithSecure Support Toolを実行するとデスクトップに作られます（wsdiag）
